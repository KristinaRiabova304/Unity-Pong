# Pong — Unity Lab, Лабораторна №1

## Варіант
**Варіант 1 — Pong** (складність 3/5)

## Як запустити
Відкрити сцену `Assets/Scenes/MainMenu.unity` і натиснути Play, або через меню редактора **Unity Lab → Run Main Menu**. Усі сцени (`MainMenu`, `PongArena1`, `PongArena2`) додані до Build Settings.

## Керування
- Гравець 1 (ліва ракетка): `W` / `S`
- Гравець 2 (права ракетка): стрілки `↑` / `↓`
- Пауза під час гри: `Esc` або кнопка **Menu** зверху екрана

## Що реалізовано (обов'язкові вимоги варіанту)
- 2 керовані ракетки з різними схемами керування (WASD / Arrows)
- Фізичний м'яч із bounce, верхня та нижня межі поля
- Окремий рахунок Player One / Player Two (Two Player Score)
- Автоматичний reset м'яча після гола (Score Zone 2D)
- Перемога після досягнення Win Score (5 очок)
- 2 ігрові сцени (PongArena1, PongArena2)
- На другій арені — 3 додаткові physical obstacles
- Перемога на першій арені веде до другої, перемога на другій завершує гру
- Усі сцени додані в Build Settings, переходи між ними коректні

Усі обов'язкові вимоги варіанту "Pong" виконані.

## Що додано поза завданням лабораторної (бонус)
- Головне меню (New Game / Exit) окремою сценою
- Пауза під час гри (Esc або кнопка Menu) з поверненням у головне меню
- Екран перемоги з іменем переможця та рахунком, кнопки Continue / Play Again / Main Menu
- Захисні зони за верхньою/нижньою стіною: якщо м'яч усе ж вилітає за межі поля, він автоматично повертається в гру замість втрати
- Обмеження швидкості м'яча кожен фізичний крок — запобігає розгону від зіткнень з ракеткою
- Розширені ракетки (ширина 0.35 → 0.6, висота 1.8 → 3.2)
- Оновлений UI: скруглені картки й кнопки з тінями, єдина кольорова тема, картки рахунку гравців, текст із "тінню"

## Технічні примітки
Точково змінено 2 готових Unity Lab компоненти:
- `GameController.cs` — `Win()` тепер завжди показує екран результату з іменем переможця замість миттєвого переходу на наступну сцену
- `BallStarter2D.cs` — додано обмеження швидкості м'яча в `FixedUpdate` (фікс бага, коли м'яч міг вилетіти за межі поля і гра "зависала" без можливості рахувати очки)

Додано 2 нові компоненти поза каталогом Unity Lab Components: `MainMenuController.cs`, `PauseMenuController.cs`.
